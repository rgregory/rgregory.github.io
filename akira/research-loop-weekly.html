Control model

Stateful, evidence-accountable commit

Memory may inform a request, but it cannot manufacture authority or self-certify completion. Each material effect needs a stateful grant, independently captured evidence, an idempotent receipt, and an independent closeout or revocation path.

AI agentsRecent work makes the boundary explicit: a policy gate must evaluate authoritative prior state; local agreement in a multi-agent system cannot establish global admissibility.
Evidence limitMost cited work is newly submitted and unreviewed, supported by bounded benchmarks and first-party architecture accounts. The synthesis is a testable design criterion, not a validated universal production architecture.
Akira applicationUse a readable execution dossier: grant, state snapshot, evidence bundle, commit receipt, and closeout. Interrupt and rerun the worker with the same idempotency key; a verifier must distinguish requested, committed, and reconciliation-required states.

Shared decision

Prototype one execution dossier, not another platform

Start with one workflow that changes canonical Markdown and may publish or invoke an external system. Bind the authorized state, issuer, accountable actor, permitted evidence, tool scope, expiry, budget, commit receipt, residual state, and rollback path into a machine- and human-readable record.

The prototype passes only when an independent reviewer can reject the action or closeout from that record, and when a missing mandatory evidence field blocks or escalates rather than being averaged away.
