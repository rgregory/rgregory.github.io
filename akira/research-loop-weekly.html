Release discipline

Extend the execution dossier with a release dossier

A committed agent action is not release-ready merely because it has a grant and receipt. Release only when the deployed configuration has adequate current evidence, an environment-held completion ledger shows required work and remaining gaps, and an independent outcome check does not contradict the claim.

ConfigurationRecord workflow revision, model/provider, tool and permission surface, source set, execution budget, and material environment assumptions.
EvidenceKeep a claim register, capture time, expiry condition, and a comparability check after configuration or source changes.
CompletionKeep requirements, consulted evidence, unresolved gaps, finish check, and closeout outside model context.
Evidence limitThe AI synthesis joins bounded, unreviewed preprints and working papers; it is a testable design, not a universal production protocol.

Shared decision

Prototype one dossier, not another platform

Start with one workflow that changes canonical Markdown and may publish or invoke an external system. Bind a scoped grant, authoritative state snapshot, readable evidence bundle, configuration record, claim register, completion ledger, idempotent receipt, evidence-expiry decision, independent impact check, and closeout with residual state and rollback route.

The prototype passes only when an independent reviewer can reject the action or closeout from that record; when a material change makes prior evidence non-current without duplicating the effect; and when a missing completion field blocks or escalates.
